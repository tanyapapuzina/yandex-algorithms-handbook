# Yandex Algorithms Handbook

Репозиторий с решениями и заметками по курсу Яндекса:
https://education.yandex.ru/handbook/algorithms

Цель репозитория - собрать аккуратное портфолио учебных алгоритмических задач:

- решения задач;
- краткие пояснения к подходам;
- заметки по темам курса;
- прогресс по разделам.

## Структура

```text
algorithms-handbook/
├── 01-introduction/
├── 02-complexity/
├── 03-data-structures/
└── solutions/
```

## Язык

Основной язык решений: Python.

## Как добавлять новую задачу

1. Создать файл с понятным названием, например `two_sum.py`.
2. В начале файла указать ссылку или название задачи.
3. Добавить краткую идею решения.
4. Проверить решение локально.
5. Сделать commit с понятным сообщением.

Пример сообщения commit:

```bash
git commit -m "Add binary search solution"
```
