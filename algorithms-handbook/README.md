# Algorithms Handbook

Здесь будут материалы по курсу Яндекса "Тренировки по алгоритмам" / "Хендбук по алгоритмам".

## Разделы

- `01-introduction/` - вводные материалы и первые задачи.
- `02-complexity/` - оценка сложности алгоритмов.
- `03-data-structures/` - структуры данных.
- `solutions/` - решения задач, если они пока не разложены по разделам.

## Формат решения

Для каждой задачи желательно хранить:

- условие или ссылку на задачу;
- идею решения;
- сложность по времени и памяти;
- код;
- примеры запуска, если нужны.
